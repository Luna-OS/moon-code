# Moon Code 0.4.0

- **Usage tab**: your plan's usage as in the Claude app – the current session, the week, the
  weekly per-model limits and the extra usage – with a warning when your pace runs out before a
  reset ("Heads up: at this pace you'll run out tomorrow at 21:10…"). It is **live**: Moon Code
  asks Claude Code's `/usage` every 30 seconds while the tab is open (that costs no usage), and
  every answer from Claude brings new numbers too. The limit moons in the Claude panel and the
  status bar follow along.
- **Account menu** (the person at the bottom left), as in the Claude app: Usage, Claude's language,
  Help, Upgrade plan, Get apps and extensions, What's new, Learn more, Get an API key, Sign out.
  claude.ai pages (upgrading, buying more usage, the apps) open inside Moon Code.
- **Claude's language**: pick the language Claude answers in (German, French, …), whatever
  language the code is in.
- **Skills**: a new view lists your personal skills (~/.claude/skills) and the open project's,
  makes new ones, installs skills from a GitHub repository (every folder with a SKILL.md), and
  puts `/skill` into the message to Claude with "Use".
- **+ in the Claude panel** now says it started a new conversation and puts the cursor in the
  message box; the clock next to it lists this folder's earlier conversations to pick up again.
