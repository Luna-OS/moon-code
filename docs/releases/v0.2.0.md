# Moon Code 0.2.0

- **Your repositories in Cloud**: pick any of your GitHub repositories for a cloud task, not only
  the open folder's. One that isn't on this computer yet is cloned into your projects folder first
  (once).
- **Updates inside Moon Code**: Settings → Updates looks for a new version on GitHub, downloads
  it in the background and installs it with "Restart and update" – no more downloading the
  installer by hand. Moon Code looks once at every start (you can switch that off) and puts a dot
  on the Settings button when a new version is out.

Coming from 0.1.0, install this one by hand once; from here on Moon Code updates itself.
