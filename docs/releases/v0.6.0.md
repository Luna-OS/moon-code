# Moon Code 0.6.0

- **The cloud tab in the Moon colours – for real this time**: Moon Code now reads every colour
  claude.ai uses, whatever it is called, and turns it into its Moon version: the grey surfaces
  become night blue, Claude's orange becomes lavender, text stays bright. claude.ai's light or
  dark mode follows Moon Code's theme.
- **Cloud is one click**: the cloud icon opens claude.ai/code right as a tab – its own sessions,
  navigation and message box, inside Moon Code. The extra Cloud side bar (repositories, new task,
  pull requests, session list) is gone, since the page has all of it.
