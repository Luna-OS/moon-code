# Moon Code 0.1.0

The first Moon Code: a code editor in the Luna-OS Moon look, with Claude Code built in.

- Explorer, search, quick open, command palette, tabs, terminal – night and day themes.
- Claude panel: sign in with your Claude account, chat in the open folder, see the model, the
  context and your plan's 5-hour and weekly limits.
- Projects: your Claude Code projects and conversations, and your GitHub repositories.
- Cloud: hand tasks to Claude Code on the web, bring cloud sessions back, Remote Control and
  Ultrareview.
- GitHub sign-in through the GitHub CLI, with your avatar and private repositories.
- Axo, a white pixel axolotl that codes along while Claude works.
- A new icon: the crescent as the opening bracket of `☾/>`.
