# Moon Code 0.7.0

- **Every file opens**: pictures (fit or real size), PDFs (with Chromium's viewer: zoom, search,
  print), sound and video (with players), Markdown as a page (Preview / Edit), any other binary
  file as a hex view – and big text files after a question instead of a refusal.
- **Working with files like in a real editor**: Open file… (Ctrl+O, or drop files on the window),
  New file (Ctrl+N), Save as… (Ctrl+Shift+S), Save all (Ctrl+Alt+S), reopen a closed tab
  (Ctrl+Shift+T), and **auto save** (Settings). Open folder… moved to Ctrl+Alt+O.
- **Claude's changes show up live**: when a file that is open changes on disk – Claude edited it,
  git switched branches – the tab takes the new text by itself; when you have unsaved changes too,
  it asks ("Take the new one" / "Keep mine"). Ctrl+Z still brings the old text back.
- **Axo instead of Clawd**: in the cloud tab, claude.ai's orange pixel mascot is your white
  axolotl now, and other orange drawings turn lavender.
- **The starry sky everywhere**: the stars shine through the code editor at night, and over the
  cloud tab.
