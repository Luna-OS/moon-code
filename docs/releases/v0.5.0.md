# Moon Code 0.5.0

- **Skills from GitHub work on Windows**: installing no longer uses git. Moon Code downloads the
  repository's archive and unpacks it itself, so the "operation not permitted" error from git's
  read-only files is gone. A link to one folder (`…/tree/main/skills/pdf`) installs just that
  skill, and private repositories work through your GitHub sign-in.
- **Pictures and files for Claude**: add them with the paperclip in the Claude panel, drop them on
  the message box, or paste a screenshot. Claude sees pictures right away and reads the other
  files (PDFs, code, notes…) when it needs them.
- **The cloud tab feels like Moon Code**: no address bar or browser buttons any more, a Moon header
  with the session's task, and claude.ai drawn in the Moon colours.
- **Claude's pull requests in Cloud**: the open pull requests from cloud sessions in the picked
  repository, with their checks, and a **Merge** button.
