# Moon Code 0.3.0

- **Cloud sessions inside Moon Code**: a cloud task's session now opens in the new **Cloud tab**
  next to your files – claude.ai/code right in Moon Code, not in a browser or the Claude app.
  Moon Code picks the session's link up as soon as `claude --cloud` prints it. Sign in to
  claude.ai in the tab once; it stays signed in.
- **Talk to a running session**: "Message" sends a follow-up to a cloud session
  (`claude -p … --cloud <session>`), and "Bring here" continues it on this computer
  (`claude --teleport <session>`), in a checkout of its repository.
- Paste any session link or ID in Cloud to open, message or bring it here. The old "Attach" is
  gone: Claude Code doesn't attach to cloud sessions interactively.
- Links in the terminal can be clicked; claude.ai/code links open in the Cloud tab.

If Google's sign-in refuses the Cloud tab, sign in to claude.ai with your email address.
